## Оставленные кандидаты

- `frontend/src/pages/SelfHostedPage.tsx`: текущая маршрутизация использует другую
  реализацию, но внешние сборщики/способы доставки не проверены достаточно для удаления.
- Игнорируемые helpers в `tmp/` исходной пользовательской папки: они попадали
  в исходный `go test ./...`, но могут использоваться текущей работой. Не удалены.
  Отдельный чистый worktree предотвращает их влияние на итоговую сборку.
- Прикладные параметры и альтернативные Compose-профили не считаются мусором
  только потому, что не используются локально. Проверены их корректные сочетания.
- Go/npm зависимости не удалены: статический поиск не доказывает ненужность
  transitive/runtime/platform-specific путей. npm advisory scan не требует обновлений.
- Snapshot подписчиков RTP и повторные запросы больших frontend-списков требуют
  профилирования, а не механической замены архитектуры.

## Временные ресурсы аудита

`scripts/audit-optimization.sh` запускает отдельные контейнеры без постоянных томов,
публикует только случайные loopback-порты и удаляет только собственные container ID
через trap. Не читает рабочий `.env`, не вызывает prune и не запускает production.
Повторный прогон оставляет исходную инфраструктуру нетронутой.

Рабочие логи сохранены в `evidence/2026-11-06/`; объёмные browser build fixtures и
локальные исходные snapshots лежат вне репозитория в `/tmp/meetspace-*` и не входят
в поставку. Временные node_modules-ссылки из worktree удалены после проверки;
для повторной сборки нужны `npm ci` в `frontend/` и `admin/` на поддерживаемом Node.
