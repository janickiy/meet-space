# Доказательства аудита 6 ноября 2026 года

Результаты относятся к исходному commit `1e27a55` и рабочему diff
`codex/full-optimization-20261106`. Полный контекст, команды, версии среды,
ограничения и интерпретация — в [итоговом отчёте](../meetspace-final-report.md).

В `2026-11-06/` сохранены:

- Исходные и итоговые Go, frontend, admin, installer и Compose журналы.
- Планы и пять замеров SQL до/после на одном конечном fixture.
- Пять прогонов microbenchmarks realtime и SFU.
- Результаты публичных browser routes, административных cycles/soak и npm audit.
- Инвентаризация отслеживаемых файлов, миграций и мест регистрации маршрутов.
- `sha256.json` с контрольными суммами остальных файлов этой папки.

Исходные regression-логи содержат намеренно воспроизведённые FAIL. Это не итоговый
результат. Пустые журналы build/vet/staticcheck соответствуют командам без вывода;
их завершение с кодом 0 проверено при исполнении и отмечено в итоговом отчёте.
В исходном frontend regression-журнале удалены пробелы на двух пустых строках;
сообщения и результаты проверок сохранены.

Полные тексты публичных статей в browser JSON заменены контрольными суммами SHA-256,
чтобы не дублировать документацию. Метаданные и результаты проверок сохранены.
Тестовые адреса и учётные данные в логах относятся к одноразовому локальному стенду.
Рабочие секреты и production `.env` в пакет доказательств не включены.

Размер JS измеряется по загруженным файлам и gzip, а не по времени загрузки страницы.
SQL execution не является HTTP latency. Короткий heap soak не доказывает отсутствие
утечки памяти. Изолированные HTTP fixtures не заменяют реальный media E2E.
