# Сборка технического руководства MeetSpace

Документ: `MEETSPACE_TECHNICAL_GUIDE_RU.pdf`. Канонический редактируемый источник: `MEETSPACE_TECHNICAL_GUIDE_RU.md`. Прежние `MEETSPACE_TECHNICAL_DOCUMENTATION_RU.*` не заменяются.

## Редакция от 7 ноября 2026 года

Руководство содержит 11 глав. Добавлены глава 8 об отдельной административной панели и глава 9 о LDAP / Active Directory. Источники и границы проверки перенесены в главу 10, поддержка - в главу 11; прежние якоря этих глав сохранены.

Описаны административные учётные записи, cookie и CSRF, порты и прокси, разделы панели, блокировка пользователей, изменяемые лимиты, SMTP и подтверждение email, аудит и технические ошибки. Для LDAP добавлены конфигурация TLS/StartTLS, DN и атрибуты, группа доступа, полный снимок, фоновые задания, коллизии email, локальные сессии и отзыв, диагностика и границы стенда LLDAP.

В каталог API добавлены 27 административных маршрутов, корпоративный вход, подтверждение email и восстановление локального пароля. Административный ответ и ошибки отделены от публичной обёртки API. Уточнено, что `users.is_admin` не даёт доступа к отдельной панели.

Словарь БД дополнен 12 таблицами. Актуализированы users, административные индексы, пределы вложений и фоновая очередь. Итоговая схема: 53 прикладные таблицы плюс реестр мигратора, 528 полей и 9 последовательностей. Описаны табличные SQL-файлы версии 50 и неизменяемая история 1-49 в `database/migrations/legacy/`.

Основа текста: коммит `f35e115858cffbec4b7fc6fcf0fc8ef80df16c60+local-migrations`. Суффикс local-migrations означает локальное объединение миграций; он не обозначает опубликованный выпуск. Обновлены исходник, PDF, отчёт рендера и параметры сборки.

## Проверка результата

Итог: 241 страниц альбомного A4, 13 схем и 165 пунктов оглавления. Проверены все 165 PDF-закладок и их страницы. Автоматическая проверка всех страниц не нашла пустых страниц, отсутствующих символов, выхода текста или изображений за поля. Шрифтовые подстановки и предупреждения рендера отсутствуют. Визуально просмотрены контактные листы всех страниц и крупные страницы новых API, таблиц, глав и схем.

Все 11 прежних изображений сохранены без изменения пикселей и размеров отображения. Две новые схемы имеют отдельные DOT/SVG/PNG-исходники. Их растровые файлы встроены без пересэмплирования; разрешение генерации ограничено, чтобы декодирование PDF оставалось в пределах штатных ограничений библиотек. Четыре прежние схемы ER 01, ER 02, ER 03 и ER 06 по-прежнему уменьшаются на 15%; другие прежние схемы не масштабировались заново.

Все 55 блоков Bash прошли `bash -n`. Команды установки из документа, отправка почты и подключение к production LDAP при подготовке PDF не выполнялись. Сведения о ранее выполненных проверках кода и условиях opt-in тестов приведены в 10.2; сборку документа не следует считать новым испытанием приложения.

## Подготовка и сборка

Нужен Python 3.10 или новее и зависимости `docs/tools/requirements-pdf.txt`. На macOS используются Arial/Courier New/Arial Unicode, на Linux - DejaVu Sans/Mono. Из корня проекта:

```bash
python3 -m venv .venv-docs
.venv-docs/bin/pip install -r docs/tools/requirements-pdf.txt
.venv-docs/bin/python docs/tools/build_technical_guide.py
```

Сборка выполняется дважды для фактических номеров страниц оглавления; несовпадение раскладки между проходами вызывает ошибку. Главы, подглавы, PDF-закладки и ссылки читаются из канонического Markdown.

При другом расположении шрифтов задайте `--font-dir /абсолютный/путь/к/шрифтам`. Параметры `--date`, `--metadata-date` и `--commit` должны соответствовать редакции текста. Значения по умолчанию закреплены на этой редакции.

## Схемы

Редактируемые схемы сервисов находятся в `docs/assets/technical-guide/`, остальные прежние ER-схемы - в `docs/assets/technical-documentation/`. Нужны Node.js, `@viz-js/viz` и `sharp`, доступные обычному механизму поиска модулей:

```bash
node docs/tools/render_guide_diagrams.cjs
node docs/tools/render_admin_ldap_diagrams.cjs
```

Первый скрипт обслуживает четыре прежние схемы; второй - только новые admin-architecture и ldap-lifecycle. PDF подключает PNG. DOT и SVG сохраняются для последующего редактирования. Настройки размеров прежних схем закреплены в GuideRenderer.

## Проверка PDF

Нужен Poppler (`pdftoppm`, `pdfinfo`):

```bash
.venv-docs/bin/python docs/tools/check_pdf.py \
  --pdf docs/MEETSPACE_TECHNICAL_GUIDE_RU.pdf \
  --output-dir tmp/pdfs/technical-guide-review \
  --render --contacts
```

Проверьте qa-report.json и PNG: единый формат, поля, кириллицу, читаемость таблиц и схем, оглавление и окончания глав. Автоматическая проверка не заменяет визуальный просмотр. При добавлении схем сравнение полного набора с прежним PDF ожидаемо меняется; проверяйте сохранность прежнего подмножества отдельно.

Меняйте Markdown, затем пересобирайте PDF. Сохраняйте уникальные якоря и относительные пути изображений. Сборка документа не устанавливает приложение, не меняет БД, не публикует файлы на сервере и не отправляет изменения в Git.
