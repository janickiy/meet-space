## Как поддерживать документацию

1. Сверять поведение с обработчиками, use case, конфигурацией и интерфейсом.
2. При изменении маршрута обновлять [API](API.md), [справочник](API_REFERENCE.md)
   и [Postman](postman/meetspace/MeetSpace.postman_collection.json).
3. При изменении запуска сверять `.env.example`, Compose, Makefile, `install.sh`
   и `scripts/release/`; указывать, к какому варианту установки относится команда.
4. Отделять статическую сверку кода от реально выполненной проверки. Для замеров,
   сканирования, восстановления и выпуска записывать дату, версию и окружение.
5. Обновлять существующее руководство, удалять утратившие силу инструкции и
   проверять ссылки. Новые руководства добавлять в этот индекс.
