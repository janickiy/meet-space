# Административная сводка и возможности продукта

Глобальное право администратора отделено от ролей встречи и группы. `owner` и `co_host` управляют своей конференцией, но не получают доступ к административной сводке.

## Назначение права

Миграция `000021_admin_capability.up.sql` добавляет `users.is_admin BOOLEAN NOT NULL DEFAULT FALSE`. Регистрация всегда создаёт обычного пользователя. После создания учётной записи оператор назначает право по **проверенному UUID** через доверенную SQL-консоль:

```sql
UPDATE users SET is_admin = TRUE WHERE id = '<user-uuid>';
```

Для снятия права установите `FALSE`. API проверяет текущее значение в PostgreSQL на **каждом** запросе `/api/v1/admin/*`; ранее выданный JWT сразу теряет административный доступ. Права нельзя назначить через клиентский запрос или роль конференции. Операцию выдачи/отзыва следует фиксировать в журнале доступа к БД: в приложении нет отдельного журнала администраторских назначений.

## HTTP-контракт

Оба маршрута требуют Bearer JWT. Ответы имеют `Cache-Control: private, no-store` и `X-Content-Type-Options: nosniff`.

- `GET /api/v1/capabilities` возвращает `capabilities.recordingModes` и безопасный `buildVersion`. Адреса провайдеров и токены не возвращаются.
- `GET /api/v1/admin/summary` дополнительно требует `is_admin`. Возвращает `item` с временем снимка, числом активных встреч/участников/записей, размером очереди, количеством отказов за 24 часа, состояниями API/media-worker и последними состояниями PostgreSQL, Redis, RabbitMQ и MinIO. Есть максимум десять недавних кодов ошибок. Идентификаторы пользователей и конференций, содержимое чата, данные фоновых заданий, SDP, пароли и токены отсутствуют.

Отказ авторизации: `401` без JWT, `403` для обычного пользователя. Если база недоступна при проверке права, маршрут закрывается с `500` без подробностей. Сводка читается по запросу, её счётчики приблизительны во время конкурентных изменений. Проверка media-worker ограничена 1,5 секунды и не раскрывает внутренний адрес.

Полные версия, коммит и время сборки доступны через публичные `/version` и `/version.json`.
Сверяйте их с манифестом, а не только с сокращённым `buildVersion`.

`buildVersion` в Docker API задаётся безопасным `BUILD_VERSION` при сборке (короткий SHA коммита или неизменяемый идентификатор выпуска). Задание развёртывания CI передаёт `CI_COMMIT_SHA`; в Compose для рабочего окружения этот аргумент обязателен. Для сборок вне Docker допускается безопасная версия исполняемого файла Go или сокращённый идентификатор ревизии VCS; при отсутствии метаданных возвращается `dev`.
