# Развёртывание публичного сайта MeetSpace

Обновление от 24 октября 2026 года: **https://meet-space.janickiy.com/**.

Публичный сайт состоит из статических файлов, которые обслуживает Apache на сервере `93.89.223.151`.
Само приложение доступно по адресу `https://meeting.janickiy.com`.

## Настройка сборки

Используйте версию Node, указанную в `frontend/package.json`, и выполните:

```sh
VITE_MARKETING_ONLY=true \
VITE_PUBLIC_SITE_URL=https://meet-space.janickiy.com \
VITE_PUBLIC_APP_URL=https://meeting.janickiy.com \
npm --prefix frontend run build

VITE_MARKETING_ONLY=true \
VITE_PUBLIC_SITE_URL=https://meet-space.janickiy.com \
VITE_PUBLIC_APP_URL=https://meeting.janickiy.com \
node frontend/scripts/check-public-build.mjs
```

Режим Marketing-only отображает главную страницу публичного сайта без восстановления
учётной записи и подключения провайдеров API. Действия с аккаунтом и рабочим пространством
ведут на абсолютные адреса приложения. В обычной сборке приложения работа с аккаунтом не меняется.
