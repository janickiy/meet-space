# Изменения технического руководства

## 19 ноября 2026 года

Основа редакции — `adf101fd6595aff4818f61b266b28175bb8311d2` из `main`. Объём уменьшен с 252 до 88 страниц альбомного A4. В руководстве 11 глав, 13 схем и 69 пунктов оглавления. [Готовый PDF](MEETSPACE_TECHNICAL_GUIDE_RU.pdf) · [Редактируемый источник](MEETSPACE_TECHNICAL_GUIDE_RU.md).

| Часть руководства | Изменения |
|---|---|
| Архитектура и клиент | Объединены карты исходников. Обновлены схемы подключения и фоновых процессов. Описаны видимость профилей и вложений, пересылка, граница очистки истории, приглашения. Убраны размеры кнопок и описание оформления. |
| WebRTC и запись | Показаны порядок offer/answer/ready, обработка ICE, окончание публикации и отключение. Разделены команда AMQP, поток пакетов SFU, обработка FFmpeg и фиксация результата в БД. Уточнены четыре режима, доступ и условия завершения после перезапуска. |
| API | В каталог добавлены три GET-маршрута: `/api/v1/search`, `/api/v1/recordings` и `/api/v1/attachments/policy`. Сохранены условия доступа, поля и ограничения сложных операций, структуры ответов, SSE, события двух WebSocket-каналов и внутренние интерфейсы. |
| База данных | Вместо карточки на каждую таблицу дан словарь по подсистемам. Сохранены все 54 таблицы и 530 столбцов с типами, допустимостью NULL, ключами и связями. Расширен обзор JSONB. Запросы к системному каталогу дают полные определения ограничений и индексов для установленной версии. Исправлена связь пользовательского аватара в ER 01. |
| Установка и сопровождение | Уточнены выбор готового образа, три способа запуска релизной сборки, первое создание администратора и продолжение работы мастера. В таблице конфигурации различены defaults приложения и значения серверной поставки. Сокращены повторы в процедурах запуска, резервного копирования, проверки восстановления и отката. |
| Админка и LDAP | Разграничены публичный и административный HTTPS, проверки Origin и CSRF, начальный и обычный вход администратора. Уточнены единый источник пользовательских аккаунтов, поведение при сетевом отказе, полный снимок, отзыв сессий, приоритет настроек SMTP и локальное хранение аватаров. |
| Вёрстка | Длинные маршруты переносятся между сегментами пути. Таблицы повторяют шапки. Короткие команды остаются целиком, а схема и её подпись размещаются вместе. Сохранён прежний адрес PDF, на который ссылается приложение. |

Результаты сверки и границы испытаний приведены в [отчёте аудита](AUDIT_REPORT.md). Сборка воспроизводится [штатным генератором](../MEETSPACE_TECHNICAL_GUIDE_BUILD_RU.md).
