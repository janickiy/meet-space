# Проверка готовности к запуску в рабочем окружении

Отмечайте пункты только после проверки конкретного выпуска. Для каждого
подтверждения сохраните дату, имя ответственного и результаты проверки.

## Ответственные и пакет выпуска

- [ ] Назначены владелец выпуска и оператор, принимающий решение об откате. Указаны контакты на случай инцидента.
- [ ] Утверждены описание выпуска, состав изменений, известные ограничения и окно обслуживания.
- [ ] Пакет для реестра образов или архив собран из чистой рабочей копии коммита. Версия, SHA, время сборки и хеш исходников совпадают с манифестом.
- [ ] Зафиксирован вариант развёртывания: отдельный сервер через мастер, classic либо hardened shared-host. Выбраны соответствующие дополнительные файлы Compose; случайная замена MinIO на SeaweedFS, томов или сети исключена.
- [ ] Все ссылки на образы неизменяемы, контрольная сумма манифеста проверена. Предыдущий пакет доступен без пересборки.
- [ ] Для этого коммита успешно выполнены проверки CI: gofmt, vet, staticcheck, сборка Go, а также проверки стиля, типов и сборки интерфейса.
- [ ] Критические сценарии вручную проверены в Chromium и Firefox. CSP проверена в ответах сервера и браузере; ограничения зафиксированы.
- [ ] Выполнены govulncheck, npm audit и проверка образов. SBOM сохранены. Уязвимости HIGH/CRITICAL не скрыты обходным флагом; ограничения отчётов указаны.
- [ ] Проверены Docker, реестр образов, исполнитель CI и `TRIVY_IMAGE`. В рабочем окружении не используется прежнее задание `deploy-dev`.

## Инфраструктура и безопасность

- [ ] Проверочный стенд независим от рабочего окружения. DNS и HTTPS/WSS доступны из реальных клиентских сетей.
- [ ] Браузеры доверяют сертификату TURNS. Проверены правила межсетевого экрана для UDP, TCP и ретрансляции; при принудительной проверке TURN выбранная ICE-пара действительно использует ретранслятор.
- [ ] Публичный IP, NAT и мультиплексирование SFU, а также диапазон портов TURN согласованы с Compose и межсетевым экраном. Проверены корпоративная и мобильная сети.
- [ ] PostgreSQL, Redis, RabbitMQ, S3, внутреннее управление, метрики и pprof недоступны публично. Административный доступ требует права, проверяемого сервером.
- [ ] Точно настроены разрешённые источники запросов, CSP, CORS и доверенные прокси. Ограничение частоты запросов по IP различает клиентов и не доверяет произвольным заголовкам перенаправления.
- [ ] Все секреты независимы и хранятся вне Git и образов; файлы защищены. Ключ шифрования токенов провайдеров включён в защищённый план восстановления.
- [ ] Проверена ротация JWT, служебных секретов, токенов метрик, TURN и провайдеров. Выход из аккаунта не считается отзывом всех JWT.
- [ ] Диски, рабочий каталог записи, тома, права UID 1000, запас места, CPU, RAM и файловые дескрипторы соответствуют измеренной нагрузке.
- [ ] Приняты риски единой точки отказа при установке на одном сервере и отсутствия бесшовного переноса активных комнат. Подготовлен план действий при недоступности.
- [ ] Проверена доставка оповещений ответственному. Наличие правила Prometheus не считается подтверждением доставки.

## Схема и данные

- [ ] Установлено `AUTO_MIGRATE=false`. Миграция явно запускается один раз до развёртывания; журнал миграций и контрольные суммы не переписаны.
- [ ] Продолжительность миграций и блокировок измерена на репрезентативной копии. Старый код проверен на новой схеме.
- [ ] На согласованное время запрещено изменение данных и выполнено резервное копирование. Учтены все процессы записи, загрузки файлов и очереди.
- [ ] Восстановление проверено в отдельном окружении: контрольные суммы, закрытость данных, доступ по подписанным ссылкам и связи между объектами приложения.
- [ ] Утверждены реальные RPO/RTO, срок хранения и защита резервной копии на другом сервере. Согласованы допустимые потери данных при аварийном восстановлении.
- [ ] Учтены ограничения резервного копирования: сохраняются текущие версии объектов и ContentType, но не история, теги, произвольные метаданные, состояние брокера или рабочего каталога записи.
- [ ] Восстановленные тестовые БД, бакеты и тестовые данные учтены для последующей адресной очистки.

## Пользовательские сценарии

- [ ] На согласованном обычном аккаунте проверены вход, получение профиля и возможностей сервера, а также отказ в административном доступе. Секреты не попадают в отчёт.
- [ ] Регистрация, вход, выход, профиль и подтверждённые ограничения восстановления пароля соответствуют USER_GUIDE.
- [ ] В браузерах проверены создание встречи, приглашение, предварительное подключение, зал ожидания и допуск, роли и повторное подключение.
- [ ] Камера, микрофон и демонстрация экрана проверены на реальных устройствах, с разными разрешениями, при смене сети и с несколькими участниками.
- [ ] Запись каждого включённого режима запускается и останавливается. ffprobe и воспроизведение подтверждают наличие медиаданных. Composite/screen_focus создают MP4/JPEG, audio_only — AAC в MP4 без превью, individual_tracks — аудио MP4 и архив исходных дорожек. Права доступа проверены.
- [ ] Проверены личные и групповые чаты, поиск в переписке, папки, звонки и их история. Вложения и скачивание защищены. Завершённые встречи открываются через `/conferences?view=past`, записи — через `/recordings`.
- [ ] Поиск по названиям встреч и сообщениям соблюдает права доступа. Email, push и календарь проверены с настроенными провайдерами.
- [ ] Если включены email, push, календарь или OAuth, они проверены с реальными учётными данными, согласием пользователя, отзывом и обновлением доступа. По умолчанию эти функции отключены или используют заглушки.
- [ ] Если включена телеметрия, она не передаёт тексты ошибок, содержимое сообщений, URL с идентификаторами или токены. Проверены серверное ограничение частоты запросов и возможность отказа от телеметрии.
- [ ] Доступность интерфейса и адаптивная вёрстка проверены вручную. Успешная сборка не считается сертификацией доступности.

## Репетиция, запуск и наблюдение

- [ ] На отдельном проверочном стенде выполнены миграция, развёртывание, базовые и медиапроверки, откат и повторное развёртывание того же пакета.
- [ ] Проверен переход в режим завершения активных WebSocket-соединений, комнат, записей и заданий. Истечение времени ожидания не вызывает скрытый принудительный перезапуск.
- [ ] До завершения работы сервиса записи прекращены новые `record.start`, обработаны ожидающие команды запуска и штатно завершены записи. Учтена возможная задержка остановки из-за возврата команд в общую очередь.
- [ ] Для конкретной версии подготовлен достоверный отчёт проверок. Разрешение на выпуск относится именно к выбранной версии.
- [ ] Согласован объём пилотного запуска: отдельное развёртывание либо глобальные флаги. Не обещан отсутствующий в приложении выбор групп пользователей для пилота.
- [ ] До запуска выбраны наблюдаемые SLI, ожидаемый объём трафика и условия остановки. SLO основаны на измерениях целевого окружения.
- [ ] После запуска проверены версии, работоспособность, авторизация, WebSocket, медиа, записи, очереди и хранилище. Сохранены фактическое число операций и период наблюдения.
- [ ] Ответственный явно разрешил или отменил запуск. При отмене выполнен безопасный откат либо выпуск исправленной версии, а заинтересованные стороны уведомлены.

## Подтверждение запуска

| Поле | Заполняется оператором |
| --- | --- |
| Версия / коммит / хеш манифеста | Не заполнено |
| URL проверочного стенда / рабочего окружения | Заполнить для конкретного выпуска |
| Результаты CI, проверки уязвимостей, браузеров и медиа | Не заполнено |
| Резервная копия / проверка восстановления / репетиция отката | Не заполнено |
| Начало / конец / число реальных операций за период наблюдения | Не заполнено |
| Решение / ответственный / время | Документ не разрешает запуск; заполнить по результатам приёмки |
